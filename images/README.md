# 🎨 Canva 이미지 넣는 곳

Canva에서 만든 그림을 **PNG**로 내려받아 아래 이름 그대로 저장하면 웹앱 카드에 자동으로 나타납니다.
파일이 없으면 이모지 타일이 대신 보입니다. (그림 문구는 `data.js`의 `CANVA_PROMPTS` 참고)

|------|-----------|
| `images/foods/`  | curry.png · cake.png · french-fries.png · lemonade.png · green-tea.png · bulgogi.png · soup.png · ice-cream.png · fried-chicken.png · pizza.png |
| `images/tastes/` | spicy.png · sweet.png · salty.png · sour.png · bitter.png · delicious.png · hot.png · cold.png · crunchy.png · yummy.png |
